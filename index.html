ConNetIt App

ConNetIt App

ConNetIt is a personal networking diary app that helps users meaningfully organize and maintain their professional and social connections. Built in Java, the app allows users to create detailed profiles for people they meet, including notes on how they met, shared interests, and a custom connection level. With features like filtering, tagging, and real-time logging, ConNetIt provides a more personal, memory-driven alternative to traditional platforms like LinkedIn. It’s currently in active development as I continue enhancing the user interface and expanding sorting and filtering capabilities for deeper network insights.

Cafe Boulange

Coffee Backery Website

Cafe Boulange is a polished, fictional storefront website developed as a front-end design and coding project. I created the visual concept in Figma and implemented it using HTML, CSS, and JavaScript, with a strong focus on responsive layout and clean user interface design. While some links (such as social icons) are placeholders, the project demonstrates a full single-page business website layout, complete with stylized content sections and interactive navigation. The design emphasizes real-world application by simulating the user experience of a boutique café and bakery. Explore the live site and detailed README below to learn more about the project.
